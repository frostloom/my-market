# R2.7：服务拆分（B+ 方案）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** ai-gateway 目录消失，七个服务平铺 services/ 与商城同构；全仓单模块；服务边界由编译器 internal/ 规则强制（大厂四条底线之①）；reconciler/event-consumer 归并 billing 域（数据所有权显性化，底线②文档化）。

**Architecture:** B+ 方案——git mv 目录树 + 全量 import 路径改写（`github.com/frostloom/ai-gateway/...` → `github.com/frostloom/my-market/...`）+ 删除第二个 go.mod 与 go.work；共享库提升 pkg/；评测工具迁 tools/；**行为零变化**（80 基线 + 四冒烟 + CI 全量背书）。

**Spec:** 用户裁定 2026-11-19（三道锁讨论）· [PRD.md](../PRD.md) §4/§11 · 新增 ADR-011（本计划产出）

## Global Constraints

- **行为不变性铁律**：除 import 路径与文件位置外零语义改动；门禁=全仓测试失败名集合与 80 基线恒等 + compose 起栈 + smoke-r0/r1 PASS + CI 四 job 绿
- 目标结构（已与用户确认）：
```
services/{gateway, billing, router, agent, mock-provider, mall-bff, mall-goods, mall-order, seckill, mall-gen}
pkg/{config,logger,metrics,redisx,tokens,trace,xid,quota,kafka,proto, mallerr,mallpage}   # importguard 退役
tools/   # 13 个评测/基准 cmd + 评测基建 internal
eval/    # 数据资产不动
```
- billing 域 = cmd/{billing,reconciler,event-consumer} 三进程一份 internal/
- 冻结证据数据一字节不动；校验器脚本如需迁移，其 manifest 记录路径按 R2.6-T2/CI-fix 先例做消费侧重锚定
- 每笔提交 conventional；分支 feat/r2.7-split

## Review Focus

1. **internal 边界真实性**：拆完后恶意 cross-import 必须编译失败（billing internal 被 mall import → build error）→ T3 专测
2. **冻结证据校验链存活**：Windows CI job（七个 verify 脚本 + scripts/tests）在迁移后全绿
3. **80 基线恒等**：import 重写的行为中性证明
4. **归宿判定正确性**：13 工具与灰色包（jev/knowledge/supportconfig/taskbench/autoroute...）的归属不产生新的跨 internal 依赖
5. **无路径双迁**：scripts 校验器与 eval 数据的相对关系只动一次
