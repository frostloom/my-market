# R2.5：月卡订阅 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 月卡成为可购商品：混合订单含 subscription 行全链路（加购→支付→开通→额度窗口内免费推理→退款=退订不退费）。

**Architecture:** billing 第四、五处加法（ActivateSubscription/CancelSubscription gRPC，复用既有 store 订阅逻辑）；mall-order worker 新增 subscribe 履约分支；退款语义按 D15（退订不退费）；goods 301 上架关联真实 plan。

**Tech Stack:** 同 R2（Go 1.26 · gRPC · GORM · compose 全家）

**Spec:** [PRD.md](../PRD.md) §2/§5.2/§13 · [ADR-005](../spec/adr/ADR-005-billing加法改造Credit与订阅.md)（本计划修订：三处→五处加法）· [api-contract.md](../spec/api-contract.md) §4/§5 · [acceptance.md](../spec/acceptance.md) R2.5 节

## Global Constraints

- billing 加法扩为**五个 RPC**（Credit/Refund/ActivateSubscription/CancelSubscription）：既有逻辑复用 store 层订阅能力（SubscribePlan/ListSubscriptions/续订），Reserve/Settle/Reverse 与充值路径依旧零改动；ai-gateway 80=80 门禁
- ActivateSubscription 语义（ADR-005）：幂等 ref；无未到期订阅→按 plan 开通本期（模拟月费校验不接真钱）；已有未到期订阅→**立即续一期**（延期）
- CancelSubscription 语义：置 auto_renew=0，**当期权益保留至窗口期满**（D15 退订口径）；幂等（已取消 no-op）；跨租户 fail-closed
- mall 侧：subscription 行履约 ref=`order_no:line_no`（ref_type="mall-sub"）；退款时 subscription 行**不退费**、调 CancelSubscription、行标记退订
- plans 数据：实现者核实 billing plans 表种子（schema.sql/seed 脚本），为 mall 商品 301 关联真实 plan_id（无则补一条最小 plan 种子）
- 环境：CGO_ENABLED=0、基础设施测试禁并发、金额分

## Review Focus

1. Activate 幂等矩阵：首次开通/同 ref 重放 no-op/已有订阅续一期/跨租户 fail-closed → T1 测试
2. 额度窗口行为一致性：开通后窗口内 /v1 调用 funding=subscription、pre=0、余额不动；超额 402 → T3 smoke 实测
3. 退款退订语义：退款后当期仍可用、不退费、auto_renew=0；重放幂等 → T3 测试
4. 混合订单三类型行并存：general+subscription 一单内各自履约互不干扰 → T2 测试
5. subscribe 行的退款-履约竞态：复用 R2 三层防护框架（复检/守卫）还是需要新窗口分析 → T3 静态推演
