# ADR-002 商品三类型与购物规则

- 状态：已接受（对应 PRD D2）
- 日期：2026-11-17

## 背景

AI 售卖沿用 gateway 现状只有两种模式（按量充值 / 月卡）。曾考虑"固定 token 数商品"，被否决：不同模型单价不同，固定 token 数要求第二套额度记账。

## 决策

- `general` 普通商品：可进购物车，混合结算，发货 mock；
- `recharge` 充值包（面值+赠送，分口径）：**仅直购**，不进购物车；
- `subscription` 月卡：可进购物车，混合结算；
- 秒杀商品（充值包/普通商品）：仅秒杀直购；
- 不存在"token 包"；token 数仅商品页按模型单价换算的营销展示。

## 理由

- 余额口径单一（分），计费内核无需新增额度概念；
- 充值包本质是钱，进购物车与"满减凑单"语义冲突，行业惯例直购；
- 月卡是标准商品，购物车/混合单自然。

## 后果

- 混合订单履约需按行分派（ship/credit/subscribe），行级幂等 ref=order_no:line_no；
- recharge 与秒杀商品加入购物车的请求被拒（MALL_30007）。
